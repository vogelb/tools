## git

Git-related tools. See the [git README](git/README.md) for usage and installation.

- [gdir](git/README.md#gdir---dir-listing-colored-by-git-state): git-dir, a colored DIR for git workspaces. Shows the color-coded git status of all files.
- [gupdate](git/README.md#gupdate---update-git-repositories-with-fast-forward-only-pulls): git-update, a repository updater for git workspaces. Updates repositories or the repositories inside selected folders with fast-forward-only pulls; defaults to all immediate child repositories.
