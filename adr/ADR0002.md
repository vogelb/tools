# ADR0002: Persist Git ignore patterns rather than expanded paths

**Status:** Accepted
**Date:** 2026-11-06
**Deciders:** Benno Vogel

## Context
The `gitignore` tool accepts wildcards. Expanding them before storage would only ignore files present at execution time.

## Decision
Store the requested patterns in the selected `.gitignore`, rather than replacing them with a list of matching file paths.

## Consequences
Git applies the patterns to both current and future files. Callers must quote wildcards to prevent shell expansion.
