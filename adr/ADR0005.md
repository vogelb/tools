# ADR0005: Restrict ignore operations to the requested entries

**Date:** 2026-11-06
**Deciders:** Benno Vogel

## Context
A repository can contain unrelated ignore rules. Listing or untracking every ignored file would extend an invocation beyond the entries the user requested.

## Decision
List and remove from the index only files covered by the requested entries that are effectively ignored by Git.

## Consequences
Unrelated ignored files are neither listed nor removed from the index. Matching must account for effective Git ignore rules, including exceptions, rather than treating a requested pattern match alone as sufficient.
