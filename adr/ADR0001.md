# ADR0001: Share the PowerShell implementation across platforms

## Context
Separate Windows and Linux implementations duplicate tool behavior and can diverge.

## Decision
Keep one PowerShell implementation per Git tool. Use thin cmd launchers on Windows and bash launchers on Linux to execute the corresponding PowerShell script. Linux launchers check for PowerShell, Git, and the companion script.

## Consequences
Behavior changes belong in the shared PowerShell implementation rather than separate platform implementations. Linux requires PowerShell 7 (`pwsh`); launchers preserve arguments and exit codes.
