# ADR0004: Resolve patterns relative to the selected ignore file

**Date:** 2026-11-06
**Deciders:** Benno Vogel

## Context
The `gitignore` tool can edit the repository-root `.gitignore` or a selected `.gitignore`. Its invocation directory may differ from the selected file's directory.

## Decision
Interpret input patterns relative to the selected `.gitignore`, not the current working directory.

## Consequences
Pattern matching follows Git's ignore-file scope. Invoking the tool from a subdirectory does not change the meaning of patterns written to the same ignore file.
