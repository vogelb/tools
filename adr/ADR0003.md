# ADR0003: Remove matching tracked files from the index

**Status:** Accepted
**Date:** 2026-11-06
**Deciders:** Benno Vogel

## Context
Adding an ignore rule does not stop Git from tracking files already in its index.

## Decision
The `gitignore` tool removes matching tracked files from the Git index while preserving their working-tree files.

## Consequences
The tool changes the index as well as `.gitignore`. Index removals appear as staged deletions, but local files remain available.
